End-to-end flow

How BlockCert AI works

Each step below performs a real operation — nothing is simulated. If a step's service is unavailable, the flow stops and says so honestly.

Institution uploads the document

The issuing institution signs in and uploads the original certificate (PDF/PNG/JPG). MIME type, extension and size are validated.

OCR extracts the fields

Tesseract.js (and pdf-parse for PDFs) read the real text. Suggestions appear in an editable review panel — a human confirms or corrects every value. Nothing is auto-approved.

Human review

The operator checks student name, register number, credential, department, dates and marks against the document preview before issuing.

SHA-256 fingerprint

The actual file bytes are hashed with SHA-256. A single changed bit produces a completely different fingerprint.

Blockchain registration

The server submits a real transaction to CertificateRegistry: fingerprint, issuer address, timestamp, revoked flag. Only the hash goes on-chain — no personal data.

QR code generated

A QR code embeds only the public verification URL (the certificate ID). Scanning opens the public verify page.

Student credential

The student sees their own certificates and a shareable digital credential profile containing only public-safe fields.

Employer verification

An employer verifies by certificate ID, document upload or QR scan — or bulk-verifies a CSV of IDs. Public verification needs no account.

Hash comparison

The uploaded document's SHA-256 is compared against the on-chain record. A mismatch means the document was altered after issuance.

AI analysis

When a document is provided and an AI provider is configured, the real AI returns a risk score with per-check findings. If AI is not configured, the result says "AI analysis is currently unavailable."

Final result

Verified · Suspicious · Tampered · Revoked · Not Found — decided by blockchain state first, AI as a supporting signal, and written to real verification history.

ⓘ AI provides a document-risk assessment. Blockchain verification confirms whether the document matches the official issuer record. AI results are not absolute proof of authenticity.
