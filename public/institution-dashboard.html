Bulk issuance

Issue many certificates from a CSV. Required columns: studentName, registerNumber, studentEmail, studentPassword, degree, certificateType, issueDate, documentPath. Optional: department, graduationYear — studentEmail and studentPassword are required: if no student account exists for that email, one is created so the student can log in with exactly those credentials and see only their certificates. Each row's documentPath must be the file name of an attached document below, or a file already in the server upload directory. Each row is processed individually with real per-row results.
